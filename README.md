# أبفيو | Apvio

مكتبة عربية متجاوبة للتطبيقات المرخّصة على iOS وAndroid. الموقع العام موجود في `site/`، ولوحة الإدارة تطبيق Next.js مستقل في `admin-prototype/` ومتصل بـ Supabase.

## لوحة الإدارة محلياً

```sh
cd admin-prototype
npm ci
npm run dev
```

أنشئ ملف `.env.local` داخل `admin-prototype/` يتضمن متغيرات Vercel التالية: `NEXT_PUBLIC_SUPABASE_URL`، `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`، `APVIO_ADMIN_EMAIL`، و`APVIO_ADMIN_URL`. لا تضف service-role key إلى التطبيق.

في إعدادات Supabase Auth، اجعل Site URL هو `https://apvio-admin.vercel.app` وأضف Redirect URL: `https://apvio-admin.vercel.app/auth/confirm`. تسجيل حساب المشرف لأول مرة يرسل رابط تأكيد إلى البريد الموجود في قائمة السماح.

## الرفع والنشر

- لوحة الإدارة تحفظ بيانات التطبيقات في `public.apvio_apps`، ولا يسمح لها إلا بحساب المشرف المدرج في `public.apvio_admin_allowlist`.
- ملفات IPA وAPK ترفع إلى bucket خاص. حد الملف 50 MiB؛ يتحقق الخادم من الامتداد وبنية ZIP وحجم الملف ويحسب SHA-256. التنزيلات تصدر روابط موقعة قصيرة العمر للتطبيقات المنشورة.
- لا تنشر إلا ملفاً تملك حق توزيعه. تأكيد الحقوق ذاتي؛ فحص ZIP لا يغني عن فحص البرمجيات الخبيثة أو التحقق من التوقيع ومصدر الملف.
- ملف `site/site-config.js` يحتوي publishable key المخصص للاستخدام العام. سرية البيانات تعتمد على RLS وسياسات Storage، وليس على إخفاء هذا المفتاح.
- `site/` هو جذر مشروع Vercel العام، و`admin-prototype/` جذر مشروع الإدارة. مشروع الإدارة يبقى محمياً أيضاً بحماية SSO الموجودة على Vercel.

## ملاحظات الإطلاق

- إعدادات المصادقة ومخزن البيانات في Supabase، وتسجيل الدخول والبناء متاحان بعد ضبط رابط إعادة التوجيه أعلاه.
- حد Supabase Free الحالي 1 GB تخزين و50 MiB كحد أقصى للملف. تحقق من [التسعير وحدود التخزين](https://supabase.com/pricing) قبل إضافة ملفات كبيرة أو زيادة الاستخدام.
- المشروع لا يتضمن ماسح برمجيات خبيثة، خدمة بلاغات إزالة، أو نظام دفع. راجع شروط الاستخدام وسياسة الخصوصية وحقوق كل ملف قبل الإطلاق.
