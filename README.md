# أبفيو | Apvio

واجهة أولية عربية لمكتبة تطبيقات الهاتف. ملفات الموقع العام داخل `site/`، ونموذج لوحة الإدارة التجريبي داخل `admin-prototype/` خارج مجلد النشر.

## تشغيل محلي

شغّل خادم ملفات ساكن من مجلد المشروع:

```sh
python -m http.server 4173
```

ثم افتح `http://localhost:4173/site/`. لوحة الإدارة التجريبية على `http://localhost:4173/admin-prototype/admin.html`؛ غير مرتبطة بالموقع العام، ولا تُنشر مع Vercel عند ضبط مجلد النشر على `site`.

## المزايا الموجودة

- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر، ومظهر داكن اختياري.
- بحث، تصفية حسب النظام والتصنيف، وفرز بطاقات التطبيقات.
- صفحة تفاصيل لكل تطبيق مع وصف التعديلات ومتطلبات النظام وبيانات الإصدار.
- نموذج لوحة منفصل لإضافة التطبيقات وتعديلها وحذفها، مع بحث داخل القائمة.
- تخزين بيانات العرض في `localStorage` على المتصفح الحالي فقط.

## حدود النموذج الأولي

- بيانات التطبيقات تجريبية. لا توجد قاعدة بيانات أو حسابات مستخدمين أو تحقق دخول.
- لوحة الإدارة نموذج محلي فقط؛ لا تستخدمها لإدارة موقع منشور أو بيانات مشتركة.
- نموذج النشرة وروابط التنزيل تجريبية.
- اختيار الملفات في لوحة الإدارة يعرض اسم الملف فقط. لا تُرفع أو تُخزّن ملفات APK/IPA.
- قبل نشر ملفات تطبيقات معدّلة، تحقّق من حق التوزيع، وافحص الملفات، وأضف بلاغات إزالة وشروط استخدام وسياسة خصوصية.

## التقنية

HTML وCSS وJavaScript بدون اعتماديات بناء أو رسوم شهرية. الخطوط من Google Fonts؛ تظهر خطوط النظام إذا لم يتوفر اتصال.

## النشر على Vercel

اجعل Root Directory للمشروع `site/` حتى لا تدخل ملفات نموذج الإدارة ضمن الموقع المنشور. هذا النموذج ثابت ولا يملك قاعدة بيانات أو نظام تسجيل دخول.


## حقوق النشر ومصادر التطبيقات

البيانات الحالية أمثلة شكلية. أضف فقط تطبيقات تملك حق توزيعها أو تعديلات مرخّصة، مع ذكر المصدر والترخيص. لا ترفع نسخًا تجارية معدّلة أو ملفات مأخوذة من مواقع أخرى من دون إذن أصحاب الحقوق.
